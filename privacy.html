Privacy Policy

Last updated: August 2026

This Privacy Policy explains what data the Discord application "Badan Statistik Nasional" (the "Bot") collects, why, and how it is used. By adding the Bot to your Discord server, you agree to this policy.

What data we collect

The Bot collects and stores the following data, scoped per Discord server it is added to:

  • Discord user IDs of server members (not usernames, emails, or any personal information beyond the numeric Discord ID)
  • Voice channel activity: total time connected to voice channels, and total time with microphone/audio active, per user
  • Invite counts: how many members each user has invited to the server, derived from Discord's invite tracking data
  • Server configuration set by administrators: selected channel IDs and role IDs used for leaderboard, invite log, achievement announcements, and auto-role features

What we do NOT collect

  • Message content (the Bot does not read, log, or store chat messages)
  • Email addresses, phone numbers, or any Discord account information beyond user IDs
  • Voice audio or recordings (the Bot only detects connection status and mute/deafen state, never audio content)

How we use this data

Collected data is used solely to power the Bot's features within the server it is added to: displaying leaderboards, assigning roles automatically based on activity/invite thresholds, and posting achievement announcements. Data is not sold, shared with third parties, or used for advertising.

Where data is stored

Data is stored on our hosting provider's infrastructure and is only accessible to the Bot's operator for the purpose of running the Bot's features.

Data retention & removal

Data for a server is retained as long as the Bot remains in that server. Server administrators can request data deletion by contacting the Bot operator. Removing the Bot from a server does not automatically delete stored data, but it can be requested.

Third-party access

The Bot's dashboard uses Discord OAuth2 for login, which only requests permission to identify the logged-in user and list servers they have access to — it does not read or send messages on the user's behalf.

Contact

For questions about this policy or to request data deletion, please contact the server administrator or the Bot's developer.
